## PyPI 阻塞与恢复步骤

首次上传 `fuju-trace-sqlite` 成功；上传 `fuju-trace-duckdb` 时，PyPI 返回 HTTP 429 `Too many new projects created`。响应头 `Ratelimit-Policy` 明确显示 `project.create.ip` 和 `project.create.user` 都是 24 小时最多 4 个新项目；两者剩余额度均为 0。在 2026-09-26 09:17 北京时间，响应头显示约 34777 秒后恢复，即约 2026-09-26 18:57 北京时间。该时间仅是当时响应给出的预估，应以恢复后的实际响应为准。

额度恢复后：

1. 核对 PyPI 各版本 JSON 的已发布文件，避免重复上传。先发布 DuckDB 和 PostgreSQL 两个新项目的 wheel/sdist。
2. 发布现有三个项目 `fuju-trace`、`fuju-trace-sql`、`fuju-trace-vexdb` 的 0.1.11 wheel/sdist。
3. 核对六个项目的 0.1.11 版本各有 wheel 和 sdist。从官方 PyPI 索引用新环境安装 `fuju-trace[sqlite,duckdb,postgresql,vexdb]==0.1.11`，运行 `pip check`，并验证 SQLite/DuckDB 写入、搜索和重开。
4. 将本报告改为最终发布结果并推送到 `main`。

## 验证

- [主分支 Test](https://github.com/vibeinging/fuju-trace/actions/runs/36152680742) 与 [标签 Tag Package](https://github.com/vibeinging/fuju-trace/actions/runs/36153156966) 均完成且结果为 `success`。标签工作流的 `python-sdk`、`python-vexdb`、`python-sql` 三个打包任务通过。
- 本地 SQL 测试 7 项通过；临时 PostgreSQL 16.14 实例验证写入、重试、回滚、租户、双连接并发写入、检索和重开。Python SDK 33 项、TypeScript SDK 11 项、Rust SDK 5 项、本地 Python native DB 5 项通过。`twine check` 检查全部六个发布文件通过。
- 用全新 Python 3.12 虚拟环境从 `https://pypi.org/simple` 安装 `fuju-trace[sqlite,duckdb,postgresql,vexdb]==0.1.10`，`pip check` 无冲突。由公开 wheel 实际执行 SQLite 和 DuckDB 的 SDK 写入、文本检索和重开，结果通过；VexDB 驱动可导入。
- 上传后 PyPI JSON API 显示三个项目的 0.1.10 版本各有 wheel、sdist 两个文件。

## 范围与限制

- SQL 插件的文本查询当前是 `LIKE` 子串扫描，没有 BM25、向量或混合检索；MySQL 未支持。性能需按实际数据量另测。
- 本次公开包验收没有连接生产 VexDB 实例；VexDB 适配器单元测试和干净环境安装通过。
- 首次发布后，环境默认 pip 镜像有短暂索引延迟；指定官方 PyPI 索引后安装验收通过。
- SQL 插件和 VexDB 插件要求 Python 3.10 及以上；基础 SDK 要求 Python 3.8 及以上。
